RWANG CONFIGURATION

Connections & access

01

ตัวตนและเสียง

กำหนดคำปลุก ภาษา และโมเดลหลักของ RWANG

Speech privacy

RWANG จะเลือก on-device recognition เมื่อ browser และ language pack รองรับ มิฉะนั้น browser อาจส่งเสียงไปยังบริการของผู้ผลิต ระบบจะแจ้งโหมดที่ใช้ก่อนเริ่มฟัง

02

Perception & identity

เลือก sensor ที่ RWANG ใช้จดจำท่าทาง ใบหน้า และเสียงแบบ local-first

Experimental convenience only

การเปิดกล้องหรือไมค์ต้องเกิดจากการกดของผู้ใช้ โปรไฟล์ทดลองถูกเก็บในอุปกรณ์นี้และใช้แสดงสถานะเท่านั้น ไม่ใช่หลักฐานยืนยันตัวตนและไม่ข้าม token หรือ approval

03

Home Assistant

RWANG เรียก REST API ผ่าน backend เพื่อไม่เปิดเผย token ใน browser

Action gate

อ่าน state ได้ทันที แต่ turn_on, lock, alarm, cover และ service อื่นจะเข้าคิวอนุมัติก่อนเสมอ

04

MCP Agent connections

รองรับ Streamable HTTP, SSE และ local stdio พร้อมตรวจ tool drift

05

IoT Webhooks

เชื่อมระบบอื่นด้วย HTTP endpoint ที่กำหนดไว้ล่วงหน้า

06

Mobile access

จับคู่ด้วยรหัสใช้ครั้งเดียวและออก credential แยกรายอุปกรณ์

LAN security

Master token ไม่ถูกส่งให้มือถือ อุปกรณ์ที่จับคู่จะได้ HttpOnly cookie อายุ 30 วันและไม่มีสิทธิ์ approve, model action หรือแก้ integration การจับคู่จากเครื่องอื่นเปิดได้เฉพาะ trusted HTTPS

07

Schedules & safety

กำหนดกติกากลางสำหรับ routine และงานที่ทำตามเวลา

Action gate

Schedule ปลุกให้ RWANG ทำงานตามเวลาได้ แต่ไม่สามารถข้าม approval policy ของ Home Assistant, MCP หรือ Webhook
